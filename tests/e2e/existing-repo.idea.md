Run inside a copy of a small project that already has code and a few passing tests, with one real bug in one area (for example, an empty input is accepted and corrupts a list). First ask RIL to add one small feature to the project. Then ask it to make the checks on the buggy area stronger. Three things to prove: the new feature works and every old test stays green; the stronger-checks request finds the bug through a failing proof and fixes it through the normal fix rounds; when the first offer to strengthen existing checks is skipped, it is not asked again.
